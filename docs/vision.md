# Product Vision: Personal Task List

The Personal Task List App is a utility designed and focused on helping individuals capture and manage daily tasks instantly without unnecessary setup or complexity.
The application is not intended to be a collaborative enterprise platform. Instead, it serves as a personal productivity utility optimized for users who value efficiency and simplicity.

## Goal

Provide users with the fastest possible way to manage personal tasks while maintaining intelligent prioritization and clean organization.  
Deliver a highly reliable and maintainable REST API.  
Ensure predictable and scalable backend architecture  
Support future extensibility without increasing product complexity  
Maintain low response times for all task operations  

## Core Capabilities
The application must support standard task lifecycle operations:
- **Task Lifecycle:** Creation, Read, Update and Delete Tasks.  
- **Dynamic Priority Engine:** The system introduces a Dynamic Priority model that automatically updates based on task urgency (OVERDUE → URGENT → NORMAL).
